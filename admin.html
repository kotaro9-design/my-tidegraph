データは1時間ごとにスプレッドシートへ集計されます（今の1時間の分も含めて表示）。利用者数は端末ごとの匿名IDの数です（ブラウザのデータを消すと別の人として数えます）。 地域は約10km単位に丸めた位置で、名前は国土地理院の逆ジオコーダで求めた目安です。 エラーの「画面」は利用者の端末でデータを受け取れなかった回数（通信の切れ目なども含む）、「サーバー」は Apps Script での処理の失敗です。 外部サイトの「サーバーから」は Apps Script の URL Fetch（1日の上限に数える）、「ブラウザから」は利用者の端末からの取得です（上限には数えない。地図タイルは端末ごとに初回のみ数える）。 データ元の異常の「ex」はサーバーからの通信の失敗・時間切れ、「net」はブラウザの通信の失敗です（利用者側の電波の弱さでも起きます）。 表示の速さの「起動〜表示」は、ページを開いてから潮位のグラフが出るまでの時間です。 流入元はページを開いたときの直前のページのサイト名です。X や LINE のアプリ内から開いた場合は「直接」になることがあります。リンクに ?from=名前 を付けると、その名前で数えます。
